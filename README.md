# 9·24 牛市叙事考古复盘

一个关于 2024 年以来港股与 A 股市场叙事演变的交互式复盘网页。项目将政策、资金、价格和业绩放在同一时间轴中，梳理 24 段代表性市场叙事及其阶段转换。

**在线查看：** https://fmiphaz.github.io/narrative-924-review/

## 内容概览

- 四轨时间轴：叙事、资金、价格与业绩的联动观察
- 叙事生命周期、资金注意力迁移和标的角色热力图
- 24 张叙事卡片，展示代表性标的的走势、成交额与关键事件
- 覆盖主要市场指数、半导体、通信、港股科技与创新药等行业基准

网页为静态单文件版本，入口是 [`output/index.html`](output/index.html)。推送到 `main` 后，GitHub Actions 会自动更新 GitHub Pages。

## 数据与说明

数据截止至 2026-07-24 收盘（Asia/Shanghai）。本项目用于市场研究与历史复盘，不构成投资建议；部分行业采用 ETF 或相关指数的跟踪口径，具体说明见网页“数据边界”部分。
